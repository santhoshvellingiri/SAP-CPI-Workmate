SAP CPI Workmate is your browser companion for SAP Integration Suite (Cloud Platform Integration). It adds a View Data button to both the Data Stores and JMS Queues monitoring pages — letting you inspect message payloads directly in the browser with zero extra setup.

Uses your existing browser session (no extra login), calls the SAP monitoring APIs, and unpacks returned zip files in-browser using JSZip. Supports syntax highlighting, line numbers, full-text search, and configurable size, theme, and font settings.
